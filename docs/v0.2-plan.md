# v0.2 plan: a native GTK 4 terminal

Goal: a terminal good enough to replace Ptyxis for everyday work, with no AI yet.
It becomes the body of aiterm: in v0.3 the agent panel and the MCP server plug
into it instead of tmux.

## Stack

| Part | Choice | Why |
|---|---|---|
| Language | Python 3 + PyGObject | Fast to iterate, reads well, the same language as the later MCP server and evals |
| Toolkit | GTK 4 + libadwaita 1 | Native GNOME look, follows the system light/dark theme for free |
| Terminal widget | VTE 3.91 (VTE for GTK 4) | The engine behind GNOME Terminal and Ptyxis: escape codes, scrollback, selection, IME |
| Packaging | Run from the repo, `install.sh` adds the launcher | No build step. Flatpak is out: its sandbox gets in the way of a terminal that must run host commands |

### apt dependencies

```bash
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 gir1.2-vte-3.91
```

On Ubuntu 26.04 GNOME already ships everything except `gir1.2-vte-3.91`
(only the GTK 3 build of VTE, `gir1.2-vte-2.91`, is installed by default).

## Structure

```
bin/aiterm-gtk                                   launcher: runs the package from src/
src/aiterm/
  __init__.py                                    APP_ID, version
  __main__.py                                    python3 -m aiterm
  application.py                                 Adw.Application: windows, app-wide CSS, (later) actions and shortcuts
  window.py                                      Adw.ApplicationWindow: header bar, Adw.TabView with terminals
  terminal.py                                    Vte.Terminal subclass: spawns the shell, colors, font, title, clipboard
  shortcuts.py                                   capture-phase shortcuts that win over VTE
data/io.github.khrystofor_main.Aiterm.desktop.in launcher template, @BIN@ is filled in by install.sh
tests/gtk_smoke.py                               opens a real window with a real bash and checks it
```

Later, as features land: `preferences.py` (settings dialog),
`data/*.gschema.xml` or a small JSON config in `~/.config/aiterm/`.

Design notes:

- **The application ID** `io.github.khrystofor_main.Aiterm` matches the
  `.desktop` file name, so GNOME ties the window to its launcher (icon, dock,
  Alt+Tab) on Wayland.
- **One process, many windows.** Launching the app again opens a new window in
  the running process, as GNOME Terminal and Ptyxis do.
- **Tabs from day one.** The window already uses `Adw.TabView`; the tab bar hides
  itself while there is a single tab, so the tabs feature only adds actions.
- **Theme.** libadwaita follows the system preference; the terminal colors are
  switched on `Adw.StyleManager:dark`, and the font follows the GNOME monospace
  font setting.

## Features by priority

Each line is one small PR. P0 is this first PR.

### P0: minimal window (done)

- [x] Header bar with the terminal title (bash sets it to `user@host: dir`)
- [x] One tab running the user's shell (bash); the window closes when it exits
- [x] Light/dark theme that follows the system, live
- [x] System monospace font, live
- [x] App menu launcher (`install.sh`)
- [x] Smoke test in `tests/run.sh`

### P1: enough to switch from Ptyxis

1. [x] **Clipboard**: Ctrl+Shift+C / Ctrl+Shift+V, middle-click paste, right-click menu (copy, paste, select all)
2. [x] **Tabs**: Ctrl+Shift+T new tab in the current folder (VTE reports it through OSC 7), Ctrl+Shift+W close, Ctrl+PgUp/PgDn, Ctrl+Tab and Alt+1…9 to switch, Ctrl+Shift+PgUp/PgDn to move, a "new tab" button in the header
3. **New window**: Ctrl+Shift+N, and a main menu (New Window, Keyboard Shortcuts, About)
4. **Safe closing**: ask before closing a tab or window while a program is running in it (not just an idle shell)
5. **Zoom**: Ctrl+plus / Ctrl+minus / Ctrl+0
6. **Search**: Ctrl+Shift+F, a search bar over the scrollback with next/previous and regex
7. **Links**: underline URLs, Ctrl+click opens them in the browser
8. **Make it the default terminal**: `xdg-terminal-exec` entry, so Ctrl+Alt+T and "Open in Terminal" use aiterm

### P2: comfort

9. **Preferences** dialog: font, palette, scrollback size, cursor shape, bell
10. **Remember window size** between launches
11. **Keyboard shortcuts** dialog
12. **Drag and drop** files onto the terminal pastes their quoted paths
13. **Long command finished** notification when the tab is in the background
14. **Unlimited scrollback** option

### P3: bridge to the AI (end of v0.2)

15. **Shell integration (OSC 133)**: prompt and command markers in bash, so the app knows exactly where each command and its output begin and end, plus the exit code. This replaces the prompt parsing in `aiterm-left` and fixes the custom-`PS1` limitation.
16. **Split view** with an empty side panel: the place where the agent goes in v0.3.

## Out of scope for v0.2

- Any AI features (v0.3)
- Split panes for several terminals
- Flatpak / .deb packaging
